## 当前行为

The planner sometimes hallucinates tool results or invents doc_ids because the system prompt doesn't explicitly forbid it.

## 根因

The planner prompt lacks a negative constraint forbidding the generation of fabricated tool outputs or non-existent document identifiers.

## 备选方案

### 1. Add a 'NEVER' section

Explicitly forbid fabricating tool results or doc_ids in the system prompt.

- 取舍：Can make the prompt more verbose; must be worded carefully to not over-constrain valid reasoning.

### 2. Add a few-shot negative example

Include a brief example of a rejected plan that invents a tool result.

- 取舍：Takes up token budget; less direct than a negative constraint.

## 选中的提案

Add a 'NEVER' section to the planner prompt: 'NEVER fabricate tool results, invent doc_ids, or claim success without a verification step.'

## 预期指标

- 指标：percentage of turns with fabricated content
- 基线：3/10 planning turns contain fabricated elements
- 目标：0/30
- 方法：Manual audit of 30 recent planning turns

## 回放计划

- Re-run the 3 failing cases
- Audit 30 recent turns for fabricated content
- Verify no new plan invents a doc_id or tool result

## 回滚

Revert the change to the planner prompt in the harness config
