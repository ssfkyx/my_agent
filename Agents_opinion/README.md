# Agents_opinion

主脑提出的 harness 修改方向归档。

这里记录的是**主脑的意见与实验方向**，不是已批准的变更：

- 不自动应用
- 不自动合并
- 不修改测试/评测器/guardrail
- 只是“主脑有能力提出 harness 修改方向”的实践证据

每条记录来自 `harness.propose_change`，包含：

- 当前行为
- 根因
- 备选方案与取舍
- 选中的提案
- 预期指标
- 回放计划
- 风险与回滚

归档目录本身：

- 不进入 RAG 知识库
- 被 guardrail 拒绝给 agent 读取，避免自反馈污染
